## 🧰 How it's built

- **One self-contained `index.html`.** No framework, no build step, no dependencies to install.
- **Vanilla JavaScript + Canvas** for the particle name, project visuals and confetti.
- **CSS 3D transforms** for the exploding stack and tilt effects.
- **Scroll-driven animations** that degrade gracefully in older browsers.
- **Accessible by default:** respects `prefers-reduced-motion`, keyboard focus states, screen-reader labels.
- **Responsive** from 390px phones to wide desktops, with no horizontal scroll.
- Fonts: *Bricolage Grotesque*, *Instrument Sans* and *JetBrains Mono* via Google Fonts.
